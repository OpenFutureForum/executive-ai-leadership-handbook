# Contributing

Contributions should improve executive usefulness, accuracy, accessibility, or source coverage. Every factual claim must be traceable to a public source. Do not submit private attendee data, personal contact information, credentials, internal documents, unpublished research, or confidential company material.

Keep quotations short and exact. Prefer links and original synthesis over duplication. Label recommendations clearly. Run `python3 tools/validate.py` before opening a pull request.
